Co pokazuje pasek

Zasady

  • Wyrównany do lewej krawędzi godziny (pion) / wyśrodkowany nad godziną (poziom). Godzina i data przesuwają się o ~22 px w dół, kafle tracą tyle samo wysokości.
  • Spokojny, przygaszony kolor (--dim). Kolor dostaje tylko stan wymagający uwagi: słaby sygnał, brak sieci, bateria ≤ 15%. Ładowanie — zielone.
  • Wi‑Fi: 3 łuki, poziomy z RSSI: ≥ −60 dBm = 3, ≥ −70 = 2, ≥ −80 = 1, rozłączone = przekreślona ikona.
  • Pasek dotyczy łączności urządzenia z siecią. Stan połączenia z domem (MQTT) dalej pokazuje stopka „Połączono z domem”.
  • Tylko ekran startowy — reszta ekranów ma nagłówki i zakładki, tam nie dokładamy.

Skąd dane

  • ESP, sygnał: gotowe — WifiService::current_rssi() / NetworkController. Odświeżanie co ~10 s przy włączonym ekranie, w uśpieniu nic.
  • ESP, bateria: ogniwa jeszcze nie ma — makieta pokazuje docelowy wygląd. Przy podłączaniu trzeba potwierdzić na płytce pomiar napięcia (dzielnik na ADC P4 albo fuel gauge — w verified-board-map.md go nie ma). Do tego czasu stan „tylko USB”: ikona wtyczki, bez procentów.
  • Telefon, bateria: sticky ACTION_BATTERY_CHANGED (poziom + stan ładowania), bez uprawnień.
  • Telefon, sygnał: NetworkCallback → WifiInfo.rssi z transportInfo; SSID nie jest potrzebny, więc bez uprawnienia lokalizacji. Na danych komórkowych: ikona zasięgu z SignalStrength.level.
  • Bez nowych tematów MQTT — oba źródła są lokalne.
