# Logitech Z906 — potwierdzony model Home Assistant

_Odczyt tylko do odczytu z 2026-10-29. To referencja dla UI; pilot nadal będzie korzystał z wersjonowanego kontraktu MQTT, a nie z tych identyfikatorów bezpośrednio._

## Sterowanie

| Funkcja w UI | Encja Home Assistant | Typ i zakres |
| --- | --- | --- |
| Zasilanie | `switch.z906_power` | switch, `on` / `off` |
| Wyciszenie | `switch.z906_mute` | switch, `on` / `off` |
| Głośność główna | `number.z906_volume` | slider, 0–100, krok 2 |
| Subwoofer | `number.z906_subwoofer` | slider, 0–100, krok 2 |
| Centralny | `number.z906_center` | slider, 0–100, krok 2 |
| Tylne głośniki | `number.z906_rear` | slider, 0–100, krok 2 |
| Źródło | `select.z906_input` | PC – analog 5.1, RCA – stereo, Optical 1, Optical 2, Coaxial, AUX |
| Efekt | `select.z906_effect` | Stereo 3D, Stereo 2.1, Stereo 4.1, No effect |
| Decode 5.1 | `binary_sensor.z906_decode_5_1` | tylko odczyt, aktywny / nieaktywny |

## Zasady UI wynikające z encji

- `Mute` jest małym przyciskiem akcji z jednoznacznym stanem, nie kaflem „dźwięk aktywny”.
- `Decode 5.1` jest wskaźnikiem informacji, nigdy przełącznikiem.
- Wszystkie cztery suwaki używają kroku 2 i rzeczywistych wartości 0–100; nie pokazujemy sztucznego balansu `+/-`.
- Wyjątek: przyciski −/+ po bokach tarczy głośności zmieniają ją o 1 (2026-11-03, prośba
  użytkownika). Kontroler przyjmuje dowolny procent mimo `step: 2` w encji HA — w HA widać
  było wartość 23. Przytrzymanie przycisku powtarza krok; tarcza nadal chodzi co 2.
- Źródło i efekt są wyborami ze ściśle określonej listy. UI nie tworzy własnych nazw trybów.
- Diagnostyka oraz `Last command` pozostają poza ekranem codziennego sterowania; należą do widoku diagnostycznego.

## Encje techniczne poza głównym ekranem

- `sensor.z906_connection`
- `sensor.z906_diagnostics`
- `sensor.z906_last_command`
