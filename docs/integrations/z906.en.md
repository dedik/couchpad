# Logitech Z906 — confirmed Home Assistant model

[Polski](z906.md)

_Read-only inspection from 2026-10-29. This is a reference for the UI; the remote will still use the versioned MQTT contract, not these identifiers directly._

## Controls

| UI function | Home Assistant entity | Type and range |
| --- | --- | --- |
| Power | `switch.z906_power` | switch, `on` / `off` |
| Mute | `switch.z906_mute` | switch, `on` / `off` |
| Master volume | `number.z906_volume` | slider, 0–100, step 2 |
| Subwoofer | `number.z906_subwoofer` | slider, 0–100, step 2 |
| Centre | `number.z906_center` | slider, 0–100, step 2 |
| Rear speakers | `number.z906_rear` | slider, 0–100, step 2 |
| Source | `select.z906_input` | PC – analog 5.1, RCA – stereo, Optical 1, Optical 2, Coaxial, AUX |
| Effect | `select.z906_effect` | Stereo 3D, Stereo 2.1, Stereo 4.1, No effect |
| Decode 5.1 | `binary_sensor.z906_decode_5_1` | read-only, active / inactive |

## UI rules derived from the entities

- `Mute` is a small action button with an unambiguous state, not a "sound active" tile.
- `Decode 5.1` is an information indicator, never a toggle.
- The volume and the three channels show the real percentage from the controller (0–100); we do not show an artificial `+/-` balance. All four, however, have only 44 amplifier levels (0–43) — the channels too (HA history 2026-11-08: Center, Subwoofer and Rear only took 0, 2, 5, 7, 9, 12…).
- Volume −/+ (in the gap of the dial and VOL on the TV screen) and the channels' −/+ and dragging
  change the value by one amplifier level. The Z906 has 44 levels (0–43): the controller rounds the
  percentage to a level and reports it back as a percentage, so only 0, 2, 5, 7, 9, 12, 14, 16, 19,
  21, 23, 26, 28, 30, 33… are reachable (about 2.3 % apart; confirmed from HA history 2026-11-05).
  A 1 % step usually left the level unchanged and ended as an unconfirmed command. Holding a button
  repeats the step; turning the volume dial still moves in steps of 2 and the controller rounds anyway.
- Source and effect are selections from a strictly defined list. The UI does not invent its own mode names.
- Diagnostics and `Last command` stay off the everyday control screen; they belong in the diagnostic view.
